Link Best Practices

  • Use descriptive text for for the link text and avoid "click here" or similar
  • When the link destination is a different website, consider using target="_blank" to open the link in a new tab
  • For links to different websites, adding the attribute rel="noopener" is a good security practice

Descriptive links help with accessibility by giving screen readers a clear destination for each link, since tabbing through a page can often mean the screen reader is reading the link text without the content around it for context.
